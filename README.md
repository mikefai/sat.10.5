# Math Atlas — 2026 Digital SAT Math guide

An independent, original study webpage covering nine requested Digital SAT Math topics. Every module has a concept breakdown, an annotated hard example with algebra and Desmos methods, three practice exercises, and a visible final answer key. Practice includes 18 four-choice questions and 9 student-produced responses.

## Run

```powershell
npm install
npm run validate:content
npm run audit:math
npm run dev
```

Open the local URL printed by Vite. `npm run build` creates a deployable `dist` folder. Practice progress stays in this browser's local storage. The **Print module** control produces a printable version of the current module.

## Content and scope

The questions are original practice inspired by the current Digital SAT Math response formats. This is a topic guide, not an adaptive Bluebook test or an official College Board product. The interface intentionally has no timed scoring. Multiple-choice responses have four options; student-produced responses accept the listed valid fraction/decimal forms where applicable.

Format and domain information was checked against the [College Board Math overview](https://satsuite.collegeboard.org/sat/whats-on-the-test/math/overview), [test structure](https://satsuite.collegeboard.org/sat-school-day/taking-the-test/structure), and [content domains](https://satsuite.collegeboard.org/practice/content-domains). Desmos regression syntax is described by the [Desmos Help Center](https://help.desmos.com/hc/en-us/articles/204349605-Log-Mode).
